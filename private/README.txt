CLEAN (bina watermark wale) ORIGINAL CERTIFICATES - YAHAN SE BAHAR KABHI MAT BHEJNA
=========================================================================
Naya certificate add karne ka tareeqa:
 1. Saaf (bina watermark) JPG is folder `certificates-original` me daalo.
      - 1 page:   naam.jpg           (jaise  iso-9001.jpg)
      - kayi page: naam-1.jpg, naam-2.jpg ...
 2. (Optional) scripts/watermark/stamps.json me us certificate ki stamp ki jagah likho.
 3. Terminal me:  npm run watermark
 4. Public folder me watermark wali JPG + thumb + PDF apne aap ban jaati hain.
Yeh folder .gitignore me hai, isliye GitHub/Vercel par upload nahi hota. Iska backup apne paas rakho.
